메르카토르 도법 탐구 시뮬레이터

위도를 바꾸며 sec 함수의 정적분, 메르카토르 세로 좌표, 위도별 확대율의 관계를 직접 확인해 보세요.

1. 위도 설정

60°
0° · 적도20°40°60°80°

극점 90°에서는 sec φ와 메르카토르 세로 좌표가 발산하므로 모형은 80°까지 표시합니다.

2. 수학적 원리

k(φ) = sec φ = 1 / cos φ

위도 φ에서의 국소 확대율입니다. 위도가 높아질수록 값이 커집니다.

y(φ) = ∫₀ᵠ sec θ dθ
y(φ) = ln |sec φ + tan φ|

φ와 θ는 공식에서 라디안 단위로 계산합니다. y는 지구 반지름으로 나눈 정규화 세로 좌표입니다.

3. 현재 위도에서 계산된 값

정규화 세로 좌표 y(φ)
1.31696
국소 확대율 sec φ
2.000 배
평균 세로 확대율 y / φ
1.258 배

정적분값은 지도상의 정규화 좌표이며, 그 자체가 확대율을 뜻하지 않습니다.

4. 위도에 따른 세로 좌표 변화

y(φ) 세로 좌표선택한 위도

곡선의 기울기는 해당 위도에서의 국소 확대율 sec φ를 반영합니다. 고위도로 갈수록 세로 좌표가 더 빠르게 증가합니다.

5. 위도별 확대율 비교

국소 확대율

sec 60° = 2.000

현재 위도 한 지점에서의 확대율입니다.

평균 세로 확대율

y(φ) / φ(rad) = 1.258

적도부터 현재 위도까지 지도상의 세로 거리와 실제 자오선 거리의 비율입니다.

6. 실시간 해석

위도 60°에서는 국소 확대율이 2배입니다. 평균 세로 확대율과 구분해 해석해야 합니다.

8. 수치 비교표

주요 위도에서의 값을 계산해 비교합니다. 선택한 위도는 표에서 강조됩니다.

위도정규화 세로 좌표 y국소 확대율 sec φ평균 세로 확대율

결과 해석 시 주의할 점

  • 정적분값 y(φ)는 적도부터 해당 위도까지의 정규화된 지도 세로 좌표입니다.
  • 국소 확대율 sec φ는 특정 위도에서의 미소한 거리 확대 비율입니다.
  • 평균 세로 확대율은 지도상의 세로 거리 y와 실제 자오선 각거리 φ(라디안)의 비율입니다. 적도에서는 극한값 1을 사용합니다.
  • 메르카토르 도법은 각도 관계를 보존하지만 면적과 거리를 왜곡합니다. 이 모형은 구면 지구를 가정한 이상화된 수학 모형입니다.
